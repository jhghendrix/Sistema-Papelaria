# 📚 Sistema de Gerenciamento de Papelaria

Projeto desenvolvido para o gerenciamento de uma papelaria, com foco no controle de estoque e no cadastro de produtos e usuários, utilizando PHP e MySQL.

## 🚀 Funcionalidades

- 🔐 Login de usuários.
- 👤 Cadastro de usuários.
- 📦 Cadastro de produtos.
- ✏️ Edição de produtos cadastrados.
- 🗑️ Exclusão de produtos.
- 📊 Controle e atualização do estoque.

## 🛠️ Tecnologias Utilizadas

- **PHP** — desenvolvimento do sistema.
- **MySQL** — gerenciamento do banco de dados.
- **HTML5** — estrutura das páginas.
- **CSS3** — estilização e layout.
- **XAMPP** — ambiente de desenvolvimento local.

## 💻 Como Executar o Projeto

1. Instale o XAMPP no computador.
2. Copie a pasta do projeto para o diretório `htdocs` do XAMPP.
3. Inicie os serviços Apache e MySQL.
4. Abra o MySQL Workbench ou o phpMyAdmin e configure o banco de dados.
5. Configure a conexão com o banco de dados nos arquivos PHP do projeto.
6. Acesse o sistema pelo navegador, utilizando o endereço local correspondente à pasta do projeto.
